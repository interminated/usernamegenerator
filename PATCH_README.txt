USERNAME GENERATOR | GAME — РЕФЕРАЛЬНАЯ СИСТЕМА v2.3
====================================================

Это PATCH к версии 2.2. Архив содержит ТОЛЬКО новые/изменённые файлы.
ВАЖНО: файл data/game.sqlite, папку data и свой .env не заменяй и не удаляй.
Сначала сделай резервную копию базы и останови сервер.

ЧТО ДОБАВЛЕНО
- Новый раздел «Друзья» на главной и в профиле.
- Персональные ссылки Telegram Mini App вида
  https://t.me/ИмяБота/ИмяПриложения?startapp=ref_<случайный_код>
- Награда 100 000 ВИРТУАЛЬНЫХ ₽ ПРИГЛАСИВШЕМУ за каждого нового Telegram-пользователя.
- Счётчик друзей, суммарные начисления, список последних приглашённых.
- Кнопки копирования и отправки ссылки в Telegram.
- Защита: засчитывается только ПЕРВЫЙ вход нового Telegram ID с проверенным
  подписанным Telegram initData, а не обычная регистрация или GET-параметр.
  Повторное открытие ссылки и подмена параметра не начисляют второй бонус.
- SQL-таблицы referral_codes и referral_rewards создаются автоматически.

УСТАНОВКА
1. Останови сервер. Сохрани резервную копию своей SQL-базы.
2. Распакуй архив в КОРЕНЬ существующего проекта с заменой файлов,
   сохранив папки lib, public и tests. Новые файлы добавь.
3. НЕ перезаписывай существующие .env и data/game.sqlite.
4. В BotHost → переменные окружения добавь:
   BOT_TOKEN=ВАШ_ТОКЕН_БОТА
   MINI_APP_URL=https://t.me/YourBotName/YourAppShortName
   где URL — РЕАЛЬНАЯ ссылка Telegram на Mini App, созданная в BotFather.
   Если настроен Main Mini App, можно использовать
   MINI_APP_URL=https://t.me/YourBotName
5. Перезапусти сервер. При запуске новые таблицы создадутся автоматически.
6. В игре открой «Друзья» и нажми «Копировать». Поделись ссылкой.
7. Для проверки: зайди по ней с ДРУГОГО, ранее не зарегистрированного
   Telegram-аккаунта. Пригласивший получит ровно 100 000 игровых ₽.

СПИСОК ИЗМЕНЕНИЙ
 server.js             — верификация referral start_param при Telegram-входе; API
 schema.sql            — таблицы реферальной системы
 lib/referrals.js      — уникальные коды, выдача награды, SQL-отчётность
 public/app.js         — экран «Друзья», кнопки, история, копирование/поделиться
 public/styles.css     — оформление экрана
 .env.example          — пример настройки MINI_APP_URL (НЕ ЗАМЕНЯТЬ свой .env)
 tests/referrals.test.js — дополнительные автоматические тесты
 PATCH_README.txt      — эта инструкция

ВАЖНО
- Это внутриигровые ₽. Реальные деньги в системе не используются.
- Работает только при корректном Telegram-входе. При регистрации логином
  и паролем без Telegram-подписи реферальный бонус не начисляется.
- Без MINI_APP_URL ссылка будет недоступна в интерфейсе, так как адрес
  Mini App нельзя выдумывать.
- 100 000 ₽ за каждого нового пользователя — очень большой приток валюты.
  Перед массовым запуском рекомендуется антифрод, мониторинг мультиаккаунтов
  и ограничение мошеннических регистраций. Подлинный Telegram ID не равен
  доказательству, что человек не управляет несколькими аккаунтами.

Тесты: npm test (нужен Node.js 22.13+).
